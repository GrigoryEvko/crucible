# old substrate.  scripts/check-derived-pins.py, check-mint-pattern.py,
# check-no-unchecked-access.py and check-row-contains-discipline.py read them
# to exempt such a file from some of their rules.  Each of the five reads a
# list with no rows as a list that exempts nothing.
