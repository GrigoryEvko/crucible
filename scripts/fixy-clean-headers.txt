# scripts/fixy-clean-headers.txt — certified-clean registry.
#
# Each path below is a top-level include/crucible/*.h header that a
# migration sweep brought to LITERAL ZERO `safety::`
# namespace references: it reaches the safety:: substrate only through
# the fixy:: umbrella (fixy::wrap::, fixy::tags::source::, fixy::handle::,
# fixy::sess::, ...).  check-fixy-clean-headers.py reads the parse tree of
# each entry and asserts that it names the `safety` namespace nowhere: not
# in a qualified name, a namespace alias or a using-directive, and not as
# `safety::` in a comment or a literal.  A migrated header describes its
# wrappers as `fixy::wrap::Tagged`, never `safety::Tagged`.
#
# `safety/` include PATHS are NOT matched: an include path is a file name,
# not a namespace.  Headers that legitimately retain `safety/Decide.h`,
# `safety/Pre.h`, or `safety/Simd.h` includes (CRUCIBLE_PRE macro +
# crucible::decide predicates + crucible::simd facade — primitives that
# live outside the safety:: namespace) can still be registered: those are
# include paths, not namespace refs.
#
# POSITIVE registry, not an exemption allowlist.  A path here is a
# promise the file is clean; the guard fails if the promise breaks.  The
# registry only GROWS — add a header the moment it reaches literal-zero.
# Deliberately ABSENT (and why):
#   - Arena.h / Saturate.h — circular-blocked; they POPULATE
#     namespace crucible::fixy::wrap from narrow substrate headers
#     rather than consume the umbrella, so they carry irreducible
#     `::crucible::safety::` re-export plumbing (documented in-header).
#   - Vigil.h / TraceRing.h / MetaLog.h / CrucibleContext.h —
#     migrated to the fixy:: spelling via the populate pattern, same as
#     Arena.h/Saturate.h above: they POPULATE
#     crucible::fixy::wrap (+ fixy::handle / fixy::tags) and carry
#     irreducible `::crucible::safety::` re-export plumbing, so they stay
#     OFF this registry.  The DEEPER reimplement (the SPSC ring to
#     PermissionedSpscChannel, the CrucibleContext field refactors, Vigil
#     mode_session->mint_vigil_mode_bridge) remains; Vigil also keeps one
#     documented substrate-mint call (safety::mint_atomic_session).
#   - MerkleDag.h / PoolAllocator.h / ... — code-clean but
#     still carry doc-comment prose mentioning `safety::*`; they join
#     the registry once that residue is reworded to fixy:: spellings.
#   - BackgroundThread.h — run() declares `namespace saf = crucible::safety;`
#     and mints every pipeline permission through it.  The text scan read
#     no `safety::` token there and certified the header; the parse tree
#     reads the alias.  The header joins the registry again when its
#     permission mints move to the new tree.
#
