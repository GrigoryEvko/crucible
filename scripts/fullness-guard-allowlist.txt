# fullness-guard-allowlist.txt — grandfathered `== <capacity>` sites.
#
# Format: path:line — <reason the equality is safe, or who owns the fix>
# Lines beginning with '#' and blank lines are ignored.
#
# check-fullness-guard.sh reports a STALE entry (exit 2) when the named
# line no longer holds an equality fullness test, so an entry cannot
# outlive the site it excuses and silently re-grandfather a future one.
#
# ── DEFECTS, NOT EXEMPTIONS ──────────────────────────────────────────
# This block held the three out-of-bounds writes the sweep found but
# could not fix, because they fell outside that change's file-ownership
# boundary.  All three are fixed and the entries are gone.  None of them
# was fixed by writing `>=`, which is what the entries proposed: each
# counter is now a type that cannot hold a value past its bound, so the
# comparison is no longer the thing standing between a caller and the
# array.
#
#   canopy/Scuttlebutt.h  ScuttlebuttDigest::count and
#                         ScuttlebuttRequestSet::count are
#                         ScuttlebuttSlotCount<capacity>, whose only
#                         mutator is reserve_next().  It refuses at the
#                         bound and hands back a proof-token index, so
#                         push() has no comparison of its own left.
#   safety/diag/JsonEmitter.h
#                         fixed_json_buffer's data/size/ok are private.
#                         That also closes the companion wrap on the old
#                         line 83, where `Capacity - size` underflowed
#                         for size > Capacity and let append() memcpy
#                         past the array.
#
# The request set did NOT gain the well_formed() the old entry asked
# for: it is an output-only local aggregate whose bound is now
# structural and whose only consumer revalidates. The header says so.

# ── NOT-FOUND SENTINELS ──────────────────────────────────────────────
# These compare an index against a container bound to detect a FAILED
# LOOKUP, not a full container.  The equality is exact by construction:
# the search returns exactly the bound on a miss, and the guard bails
# before any indexed access.  `>=` would be equally correct but says
# something weaker than the code means.
