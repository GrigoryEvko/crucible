# fullness-guard-allowlist.txt — grandfathered `== <capacity>` sites.
#
# Format: path:line — <reason the equality is safe, or who owns the fix>
# Lines beginning with '#' and blank lines are ignored.
#
# check-fullness-guard.sh reports a STALE entry (exit 2) when the named
# line no longer holds an equality fullness test, so an entry cannot
# outlive the site it excuses and silently re-grandfather a future one.
#
# ── DEFECTS, NOT EXEMPTIONS ──────────────────────────────────────────
# This block held the three out-of-bounds writes the sweep found but
# could not fix, because they fell outside that change's file-ownership
# boundary.  All three are fixed and the entries are gone.  None of them
# was fixed by writing `>=`, which is what the entries proposed: each
# counter is now a type that cannot hold a value past its bound, so the
# comparison is no longer the thing standing between a caller and the
# array.
#
#   canopy/Scuttlebutt.h  ScuttlebuttDigest::count and
#                         ScuttlebuttRequestSet::count are
#                         ScuttlebuttSlotCount<capacity>, whose only
#                         mutator is reserve_next().  It refuses at the
#                         bound and hands back a proof-token index, so
#                         push() has no comparison of its own left.
#   safety/diag/JsonEmitter.h
#                         fixed_json_buffer's data/size/ok are private.
#                         That also closes the companion wrap on the old
#                         line 83, where `Capacity - size` underflowed
#                         for size > Capacity and let append() memcpy
#                         past the array.
#
# The request set did NOT gain the well_formed() the old entry asked
# for: it is an output-only local aggregate whose bound is now
# structural and whose only consumer revalidates. The header says so.

# ── NOT-FOUND SENTINELS ──────────────────────────────────────────────
# These compare an index against a container bound to detect a FAILED
# LOOKUP, not a full container.  The equality is exact by construction:
# the search returns exactly the bound on a miss, and the guard bails
# before any indexed access.  `>=` would be equally correct but says
# something weaker than the code means.
#
# ── HOW THESE SIX RETIRE ─────────────────────────────────────────────
#
# Not with a refined index type.  A refinement bounded at N-1 cannot
# represent the miss at all, and one bounded at N cannot tell the miss
# apart from a real index N any better than the raw std::size_t does.
# The sentinel is not a range problem — it is an optionality problem
# wearing a range's clothes.
#
# The shape that retires them is the one the tree already uses for this
# job: a strong index with a none() state, the CRUCIBLE_STRONG_ID
# pattern from the Code Guide (`.raw()`, `.is_none()`, `none()`).  A
# search returns that type instead of std::size_t, the caller writes
# `slot.is_none()` instead of `index == bound`, and the comparison the
# guard scans for stops existing.  Where the index then feeds an
# indexed access, the caller converts once after the guard, which is
# also where a `bounded_above` refinement becomes useful — but the
# refinement is the second step, not the first.
#
# Per site:
#   topology/Pingmesh.h        find_peer() -> PeerSlot.  Note that the
#                              same idiom also appears at :256 and :280
#                              spelled `!= MaxPeers`, which this guard
#                              does not scan at all, so the `==` half
#                              being allowlisted understates how much of
#                              this sentinel is unaudited.
#   observe/SdcDetect.h        the cogs_ linear search -> CogSlot.
#   observe/SyntheticProbe.h   find_peer() -> PeerSlot; retires :278,
#                              :291 and :327 together.
#   diag/RowMismatch.h         `start` is a scan cursor, not a lookup
#                              result.  A none()-carrying index is the
#                              wrong shape for a cursor; this one wants
#                              the scan to return an explicit
#                              found/exhausted result instead.
#
# The RowMismatch row is now two: 5b0ad895 underscored the original and
# added the foundation copy, and an entry is keyed by path, so one site
# in two files needs two entries.  Six of the seven live under
# include/crucible/, so the edit does not belong to
# whoever owns this file.  It is recorded here so the next reader does
# not reach for a refinement and find it does not fit.
