# ── DEFECTS, NOT EXEMPTIONS ──────────────────────────────────────────
# The three entries in this block are REAL instances of the #62 bug
# class, found by the sweep that produced this guard.  They are listed
# here only because they fall outside the file-ownership boundary of
# the change that added the guard.  Each is an out-of-bounds WRITE on a
# public counter.  Remove the entry when the site is fixed; the fix in
# every case is `>=`, or privatising the counter behind its push.

include/crucible/canopy/Scuttlebutt.h:223 — DEFECT, worse than :164. ScuttlebuttRequestSet::push, public `std::uint16_t count`; line 226 writes entries[count]. include/crucible/safety/diag/JsonEmitter.h:95 — DEFECT. detail::fixed_json_buffer::push, public `std::size_t size` over a raw `char data[Capacity]`; line 99 writes data[size++]. Companion defect on line 83: `s.size() > Capacity - size` wraps when size > Capacity, so append() overflows through the same hole. Only instantiation today is a function-local at line 281, so reachability is low. Fix: `>=` on :95 and `size > Capacity || s.size() > Capacity - size` on :83.
