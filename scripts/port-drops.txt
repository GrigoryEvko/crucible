# port-drops — superseded-header symbols that deliberately have no home
# in the new tree.
#
# scripts/check-port-completeness.sh enumerates every public symbol of
# every `_Foo.h` under include/crucible/ (the underscore is the superseded
# marking, so that set is exactly what the project claims to have ported)
# and requires each to exist by name under include/foundation/ or
# include/fixy/.  A symbol that was not carried on purpose is listed here
# with one sentence saying why.  A symbol that is neither present nor
# listed is a missing port and fails the guard.
#
# Each entry is `<header>:<symbol>  — <one sentence>.`  The header path is
# relative to the include root, so it starts with `crucible/`.  The entry
# is keyed by symbol: name any one superseded header that declares it and
# the entry covers every header that declares it, so a template dropped
# with its specialisations, or a class with its forward declarations,
# takes one line.  The sentence is the audit surface: write what happened
# to the symbol, not what the surrounding subsystem does.  "Deferred to
# task N" is a valid sentence; the entry then drains itself when that
# task lands.
#
# An entry is checked in both directions, so this file drains in lockstep
# with the code, the way the syscall allowlist does:
#   - STALE:    the header no longer declares the symbol — remove the entry;
#   - OBSOLETE: the symbol now exists in the new tree — it is no longer a
#               drop; remove the entry.
# Either is exit 2 from the guard.
#
# To add an entry, run `scripts/check-port-completeness.sh --emit-drops`:
# it prints a template line for every current miss.  Replace the angle-
# bracket placeholder with the sentence.  Do not add an entry to make the
# guard green; add it because the symbol has no business in the new tree.
#
# Entries whose sentence begins "Deferred to" are not drops.  They are
# gaps with a task number, kept here so the guard stays runnable while
# the task is open; each drains when the task lands.  Today: the fork's
# spawn context (#116).  Two groups have drained so far, each when the
# guard reported its entries obsolete: the monotonic clock's gate and
# clamp (#183) came back to fixy/os/Time.h as a port, and the five named
# contexts (#181, the A3.2 half) came back to foundation/effects/Ctx.h
# as aliases of the witnesses that already carried their rows, so that
# A11.3 promotes them from a declaration the old tree's deletion cannot
# erase.
