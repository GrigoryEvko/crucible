# use-after-move-allowlist: the reviewed uses after std::move that
# scripts/check-use-after-move.py admits.
#
# Format: path:function:key, or path:function:key xN for N findings.  The
# key is the spent name or member path, as the guard prints it.  The guard
# reports the first use after each move, so N counts moves, not reads.
# Each paragraph starts with a comment that names the probe that its
# entries make.  The guard refuses an entry that admits more findings
# than it finds, so the list shrinks when the code changes.
#
# Only a test that probes a moved-from object on purpose is on this list,
# and a macro of the frozen old tree that forwards.  Each probe entry reads
# the object after the move to prove the state that the move leaves, or uses
# it to prove that the use aborts.
