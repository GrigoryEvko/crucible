# hatch-total pins the count of discouraged, type-checked escape
# hatches (from_raw, from_raw_nonnull, into_raw, release,

# quietly.  Removing a hatch lowers it and is refreshed here too.

# that is neither an accessor nor a mint nor a hatch, but is safe
# for the stated reason.  The list only shrinks — a bare door is
# reclassified, never added.  Regenerate with --refresh in the same
# commit that removes one.
