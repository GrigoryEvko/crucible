# scripts/mint-hs14-floor-allowlist.txt — grandfathered HS14 floor deficits.
#
# Format: `mint_name|path` (one per line, path relative to project root).
# A member mint is keyed `Class::mint_name|path`.
# No line number: a mint moves down its own header every time an edit lands
# above it, so a line key stales on contact.  Name plus path is a content
# key in the sense the sibling guards use — it survives line drift and
# still pins the entry to one declaration site.  Comments start with '#'.
# Blank lines ignored.
#
# Why this file exists.  HS14 (CLAUDE.md §XVIII) demands two negative-compile
# fixtures per mint, because a `requires` clause with no witness that it
# FIRES is a comment.  Each time the gate reached more of the tree, it found
# mints that nothing had ever asked for fixtures.  The sections below record
# those deficits by the scan extension that surfaced them.
#
# Listing them here keeps the gate doing its actual job.  A mint added
# tomorrow without fixtures reds CI immediately; these entries are tracked
# debt instead of an invisible hole or a blanket red that trains everyone to
# ignore the gate.
#
# Every entry is a TODO.  Write the fixtures, delete the line.  A stale
# entry — one naming a mint that now meets the floor, or that was renamed
# or moved — reds CI at exit 2, so the file drains in lockstep and cannot
# quietly outlive the debt it records.
