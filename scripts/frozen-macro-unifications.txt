# frozen-macro-unifications — the reviewed body changes of a macro unification.
#
# A frozen header can drop a macro definition when an include that it adds
# brings in the foundation definition of the same name.  When the old body and
# the new body differ, scripts/check-frozen-tree.py admits the drop only
# through a row here.  A body that is token-equal to its foundation twin needs
# no row.
#
# A row has five non-empty fields, separated by ' — ':
#
#     NAME — COMMIT — OLD BODY — NEW BODY — REASON
#
# COMMIT is the commit that proved the new body at least as strict as the old
# one.  A body is the canonical token form that the guard prints when it
# refuses a pair: the parameter list, then the replacement list, one space
# between tokens, and '= ' before the body of an object-like macro.  A row
# whose new body no foundation header defines admits nothing, and the guard
# refuses the unification that needs it.
