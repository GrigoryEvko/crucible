# syscall-capability allowlist — grandfathered bare-syscall sites.
#
# Each entry is `path:<call text>  — <effects::* cap proof + note>`.  The key
# is the trimmed source of the call line with its trailing `//` comment
# removed, not a line number: an edit above the call shifts nothing, and an
# entry goes stale only when the call itself is rewritten or removed.  A
# stale entry is exit 2 from check-syscall-capability.py, so the file drains
# in lockstep with the code.  Two calls with identical text in one file share
# one entry; write prose that covers both.
#
# To add an entry, run `scripts/check-syscall-capability.py --emit-keys`: it
# prints a template line for every live site that is neither allowlisted nor
# marked, with the syscall(s) the line invokes already named.  Fill in the
# capability and the function.
#
# A site covered by an in-statement `// SYSCALL-CAP-OK:` marker is exempted
# by that marker and is deliberately absent here.
#
# The prose after the em dash is the audit surface, and check-syscall-capability.py
# holds it to the sites that the key names.  The prose must name a syscall that
# the line calls.  Each SHOUTING_SNAKE word in it must be an identifier or a macro
# token of that file, not only a comment.  Its `via <function>` clause must name
# the function that holds each call: the namespaces and classes are optional,
# and more names are joined by `and`.  Write what the line actually does, not
# what the surrounding subsystem does.
