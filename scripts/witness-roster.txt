# scripts/witness-roster.txt -- every type in the new tree that attests
# to a fact it cannot see, and the door it keeps.
#
# Read by scripts/check-witness-roster.sh (the walk, the generator and
# the drift check) and by test/fixy/CMakeLists.txt (one negative-compile
# test per closed line).  This file is the only place a witness is
# named.
#
#   <type> | <header> | <forging expression> | <reason> | <status>
#
# type        the CLASS as a caller spells it, template arguments
#             included -- not an alias, because the second regex is the
#             last name segment and the compiler prints the class it
#             refused (Linear<int> is refused as Qtt(...)).
# header      relative to include/
# expression  the raw data a forger would hand the constructor.
#             forge::lvalue<T>() and forge::rvalue<T>() stand in for a
#             T& and a T&& the forger would have to hold.
# reason      private | deleted | no-match -- the refusal the fixture
#             must see.  For an open entry, the task that owns the hole.
# status      closed -- a fixture is generated and must be rejected
#             open   -- a known hole; no fixture, tolerated by the walk
#
# A line is closed only after the expression was compiled and refused
# with exactly one error carrying the reason and `<Base>(`.
