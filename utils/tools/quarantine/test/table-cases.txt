# The rule tables of the two readers.  check_plugin.py writes each table to a
# file of its own, and gives that file to the two readers of the rule table:
# the quarantine plugin and utils/scripts/layer_rules.py.  Most tables are
# malformed, and each reader must refuse such a table at the line of the
# case.  The plugin must give the error of the case and no other error, and it
# must stop when it loads.  Each reader must accept each other table, which
# is at the edge of a rule.  check_plugin.py adds the tables of each
# white-space character.
#
# THE FORMAT
#   A line `case NAME` starts a case.  The next line is `refused LINE: MESSAGE`,
#   with the line of the bad row in the table and the message of the plugin,
#   or `accepted`.  Each line after it, up to the next `case` line, is a line
#   of the table.  The empty lines at the end of a case are not part of the
#   table, and a line of a table does not start with `case `.

case an unknown row kind
refused 1: the row kind is unknown; the kinds are layer, allow, door, admit, quarantine, enforce and language
bogus x/

case a rank that is not digits
refused 1: a layer row is 'layer NAME RANK PATH...', with a RANK of digits
layer low x include/

case a rank of two layers
refused 2: the rank belongs to a second layer
layer one 0 a/
layer two 0 b/

case a layer with two rows
refused 2: the layer has a second row
layer one 0 a/
layer one 1 b/

case a path in a layer row and a quarantine row
refused 2: the path a/ is also in the layer one
layer one 0 a/
quarantine a/

case an allow row of no layer
refused 1: the allow row names the layer none, and no layer row gives it

case a header with no angle brackets
refused 2: an allow row is 'allow LAYER HEADER', with a HEADER in angle brackets
layer one 0 a/
allow one cstdint

case a door whose owner is a directory
refused 1: a door row is 'door HEADER OWNER', with a HEADER in angle brackets and one OWNER file of the source root

case a door whose owner is a file of the build directory
refused 1: a door row is 'door HEADER OWNER', with a HEADER in angle brackets and one OWNER file of the source root

case a layer row with a path of the build directory
