# The rule table of the base layers and of the quarantine.
#
# The quarantine plugin of utils/tools/quarantine/ reads this table through
# utils/tools/quarantine/rows.h, and the Python rules read it through
# utils/assay/core/ruletable.py.  So each rule has one source.  The two readers
# obey the rows grammar of utils/assay/core/rows.py, and the rule rows-readers
# compares them.
#
# THE FORMAT
#   One row on each line.  A space or a tab divides the words of a row, and a
#   row holds no other white-space character.  A line that starts with '#' is
#   a comment, and an empty line is no row.  A row can end with '| REASON'.
#   An admit row must have a reason, and an ENTRY has one admit row at most.
#   A RANK and an arity N are runs of the digits 0 to 9, with a value of at
#   most 2147483647.  A PATH is relative to
#   the source root.  A PATH that ends with '/' is a directory, and each other
#   PATH is one file.  A PATH that starts with @build/ names a file that the
#   build writes, such as a generated header, by its path inside the build
#   directory.  The name is the same in each build directory, and only a
#   quarantine row and an enforce row can hold it.  A HEADER is a name in
#   angle brackets, as an #include directive spells it.
#
# THE ROWS
#   layer NAME RANK PATH...
#       A layer of the base.  Each file under a PATH of the row is a base file
#       of the layer.  A base file can include a header of its own layer and
#       of each layer with a lower RANK.
#   allow LAYER HEADER
#       A file of LAYER, and a file of each layer with a higher RANK, can
#       include the header HEADER.  Each other header that is not in the
#       source root is a finding in a base file.
#   door HEADER OWNER
#       The file OWNER is the one file of the source root that can include
#       the header HEADER.
#   admit ENTRY [RESTRICTION...] | REASON
#       A quarantined file can name the standard library entity ENTRY.  Each
#       restriction comes one time at most, in any order, and `in` comes last:
#         until FAMILY  The family of the base that replaces the entry.  The
#                       row goes when that family lands, and `rg 'until
#                       FAMILY'` finds the rows of one family.
#                       utils/assay/guard/legacy/check_admitted_audit.py makes sure that
#                       each such row has the verdict REPLACE of that family.
#                       Each use that the row admits is a finding of the kind
#                       replace-pending:ENTRY, so the ratchet refuses a new use
#         arity N       The entry admits only a function with N parameters
#         parameters    The entry admits its class only as the type of a
#                       parameter.  The names in the class stay admitted
#         plain-result  The entry admits only a function whose result type
#                       holds no bool and no enumeration: not the type itself,
#                       not an element of an array and not a member or a base
#                       of a class.  A dependent result type is refused
#         consteval-only
#                       The entry admits only a consteval-only class and the
#                       members of one: a class that holds a std::meta::info,
#                       such as std::vector<std::meta::info>.  The language
#                       permits such a class only in a constant evaluation.
#                       A dependent type and a dependent name are refused
#         concepts      A header admits only the concepts that it declares
#         unless MACRO  The plugin refuses each unit that defines MACRO
#         in PATH...    The entry admits only in the files under the PATHs.
#                       Each PATH is a path of the base, so the row admits
#                       nothing in a quarantined file.  The plugin reads a
#                       file of the language (a language row), and the row
#                       admits in one under a PATH
#       A qualified name admits the entity and each name in it, such as
#       std::tuple_size<T>::value for std::tuple_size.  It admits no other
#       name that starts with the same text: std::tuple_size_v needs its own
#       row.  A header admits each entity that the header itself declares:
#       the file that an #include of that exact name enters, and not a header
#       with the same last name in a different directory.
#   quarantine PATH
#       Each file under PATH is quarantined.
#   enforce PATH MODE
#       MODE is report or error.  Each finding in a file under PATH that has
#       error mode is a compile error in each build.  A finding in report mode
#       is a line of the section .crucible.quarantine of the object.  A change
#       of the mode of a file compiles again only the units with a finding in
#       that file, and a change of a reason or of a comment compiles nothing.
#   language LAYER PATH...
#       Each base file under a PATH is a file of the language.  It can include
#       a header outside the source root only if the allow rows give it to
#       LAYER or a lower layer, and to its own layer.  The type of each
#       declaration in it, also a local one, uses no library class,
#       enumeration or typedef that no admit row admits there.  Each
#       expression in it, also an unevaluated operand, names no library entity
#       that no admit row admits there.  A row with `in` admits in a file of
#       the language under one of its paths.  A row with `until` admits there
#       only with `in`, and each such use is a finding of its pending kind.
#       Each other finding in a file of the language is a compile error in
#       each build.  A PATH is in one language row at most, and it must be a
#       path of the base
#   seal ROOT PREFIX...
#       The include closure of the file ROOT holds no file under a PREFIX,
#       and no file of the closure names the namespace of a PREFIX.  The
#       namespace of a PREFIX has one name for each directory after
#       include/, such as crucible::ledger for include/crucible/ledger/.  Each
#       PREFIX is a directory under include/, and a ROOT has one seal row at
#       most.  The rule detsafe-ledger holds each seal row.  It also makes sure
#       that each ROOT exists, and that each row seals each directory named
#       ledger under include/ and the namespace ledger of each project root
#   heavy HEADER | MEASURE
#   light HEADER | MEASURE
#       The header HEADER outside the source root costs more than the limit of
#       the rule heavy-include of utils/registry.txt (heavy), or no more
#       (light).  MEASURE gives the seconds and the lines of a compile of the
#       header alone, or `unmeasured:` and the reason, and an unmeasured header
#       is heavy.  `loop derive header-costs` (utils/assay/loop/derive/
#       header_costs.py) writes these rows after the marker comment at the end
#       of the table, and no other row can be after that comment.  A file under
#       include/ that includes a header outside the source root with no heavy
#       row and no light row is a finding of the rule heavy-include
#   cite PREDICATE PROCEDURE...
#       A parameter of a refinement type of fixy whose predicate is an object
#       or a type of the class PREDICATE, a qualified name with no template
#       arguments, carries the proof of that predicate.  A precondition of the
#       same function that calls decide::PROCEDURE on the parameter tests the
#       proof again, and the rule refined-pre-subsumption refuses it.  A
#       PREDICATE has one cite row at most
#   grant FILE ALIAS ENUMERATION [DOOR...]
#       The type alias ALIAS of the file FILE names each system call that the
#       code of FILE issues, as an enumerator of ENUMERATION.  The code of FILE
#       is each body of FILE, and each expression that a macro body of FILE
#       spells where a unit expands the macro.  A function of a DOOR file that
#       the code of FILE calls stands for each system call that its body
#       issues.  The rule syscall-grant-coverage refuses each system
#       call of one set that the other set does not hold.  ALIAS and
#       ENUMERATION are qualified names, and each FILE and DOOR is one file of
#       the source root.  A FILE has one grant row at most
#
# THE LONGEST PATH
#   When the PATHs of two rows hold one file, the longer PATH decides.  A
#   layer row and a quarantine row decide the class of a file in this way.
#   The plugin gives an error for a file under the source root or in the
#   build directory that no layer row and no quarantine row holds.  A file
#   that no enforce row holds has report mode.
