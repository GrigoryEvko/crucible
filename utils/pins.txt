# utils/pins.txt — the pinned tools of the tree.  This file is the only place that gives their versions.
#
# assay.core.pins reads this file for Python, and cmake/CMakePin.cmake reads the rows of cmake for CMake.  The
# rows obey the rows grammar of assay.core.rows: a word is a field KEY=VALUE, and " | " divides the cells.
#
#   pin NAME via=VIA version=VERSION [source=URL] [sha256=DIGEST | commit=SHA] [platform=PLATFORM] | WHAT IT IS
#
# via=archive  `setup install` downloads the source, makes sure that its SHA-256 is the digest, and unpacks it
# via=pip      `setup install` writes a requirements file with the digest, and pip makes sure of the digest
# via=git      the source is a git repository at the commit
# via=host     the host gives the tool, and the version is the minimum version.  The row has no source
#
# A platform is the system and the machine of a host, such as linux-x86_64 or darwin-aarch64.  A row with a
# platform serves only that host, and a row with no platform serves each host.  The key of a row is its name and
# its platform.
#
# To change a pin, write the new version, the new source and the SHA-256 of the new download, and read the
# digest from the download itself, not from a SHA256SUMS file of the release.  `python3 utils/bin/setup list`
# prints the table, `python3 utils/bin/setup install` installs the tools, and `python3 utils/bin/setup check`
# makes sure that each installed tool agrees with its pin.
