# Each fixed list of two or more elements whose element type has a padding
# bit gives a line of the rule padded-list, and the module of the rule keeps
# each list of more elements than the threshold of its row of
# utils/registry.txt.  The header is base code, so it counts only in its
# sentinel unit, and the base main file counts in its own unit.  The lines
# below cover each shape that the rule refuses:
#   - an alias of std::inplace_vector, of std::array, of an array of arrays
#     (the count is the product of the counts), of a class template that
#     holds a list and of a C array.  The unit completes each specialization
#   - a padding of a bit-field and of the 80-bit long double, in bits
#   - a data member, a C array data member and a variable
#   - the return type and a parameter by value of a function
#   - a variable of an unnamed namespace of a source file, of a named
#     namespace inside it, and of an extern "C" block.
# The rules no-raw-array-member and process-wide-state give lines here too.
# In the mode error, each line other than a record is an error, also a line
# of a list under the threshold.  The quarantined unit test/other.cpp
# includes the header, and it is not the sentinel unit, so it gives no line.
compile sentinel src/lists.cpp sentinel=include/fixy/Lists.h stage=c
exit sentinel pass
