# A build of the configuration x86_64-release, which the ledger does not
# hold, compiles the arm.  The rule judges that build against the largest
# count of each key over the configurations of the ledger.  The
# configuration x86_64-debug-tsan counts the call of close, and no
# configuration counts the call of dup, so the call of dup is an error (THE
# POLICY of assay.core.configuration).

compile raw src/raw.cpp rules=utils/rule-table.txt stage=c
flag raw -DPLANTED_ARM
exit raw pass
judge raw
configuration x86_64-release
finding raw quarantine c-library-call src/raw.cpp:9:19 | close
finding raw quarantine c-library-call src/raw.cpp:9:25 | dup
