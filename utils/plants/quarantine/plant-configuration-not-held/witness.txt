# A build of the configuration x86_64-release, which the ledger does not
# hold, compiles the arm.  The rule judges that build against the base rows,
# and no base row counts the call of close, so the call is an error.  A build
# of a configuration that the ledger does not hold does not skip the rule
# (THE POLICY of assay.guard.engines.plugin.counted).

compile raw src/raw.cpp rules=utils/rule-table.txt stage=c
flag raw -DPLANTED_ARM
exit raw pass
judge raw
configuration x86_64-release
finding raw quarantine c-library-call src/raw.cpp:9:19 | close
