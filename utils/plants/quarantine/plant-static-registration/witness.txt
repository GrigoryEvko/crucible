# The front end registers the destructor of each static object with a call
# that keeps the place of the first registration of the unit, here the
# guarded static of Table.h.  Each reference in such a call takes the place of
# its object (registered_object of expression.cpp).  So an opt-out region
# around the object covers each finding of its registration, and the mode
# error passes.  The same object outside a region gives its findings at its
# own line, and the mode error fails.  No unit gives a finding in Table.h.

compile registered registered.cpp
flag registered -isystem ../outside
exit registered pass
