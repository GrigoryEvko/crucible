# The class of a source file of the base against the rule table of the
# repository, in a tree with the paths of the repository.  A file of src/fixy/
# is a base file of the layer X1_wrappers, and a file of src/fixy/session/ is a
# base file of the layer X5_session.  No row of src/fixy/concurrent/ holds a
# file, so a file there is a file of X1_wrappers too.  No allow row gives
# <csetjmp>, so an include of it names the layer of the file.  The enforce row
# of src/fixy/ with the scope include makes that include an error in the mode
# report.  Such a file is the sentinel of its own unit, so a std name that no
# admit row admits is a finding of the kind base-std-entity, and no error in
# the mode report.  A file of src/foundation/core/ is a file of the language of
# the layer F0_primitives, so a std name that no admit row admits there is an
# error in each mode.  A file of the language reads no allow row with `until`,
# so an include of <string_view>, which such a row gives to the layer F0_core,
# is an error there too.
