# The six ordered layers of foundation against the rule table of the
# repository, in a tree with the paths of the repository.  From the lowest
# rank to the highest, they are algebra, lattices, diag, effects,
# permissions and rest.  An include of a higher layer is a finding of the
# kind upward-include, also between two directories of foundation.  So a
# lattice that includes an effects header, a diag header that includes an
# effects header and an effects header that includes a permissions header
# are each refused.  With no plant, each file has no finding.
