# One object of a header gives one finding in each unit that includes it.  The
# unit first_full makes the specializations of std::span and std::array first.
# GCC then prints the types of the header there with the default extent and
# with the parameter name Other.  The unit first_default prints them with no
# extent and with the parameter name Count.  The entity of each object holds
# no printed type, and the two units then give the same finding lines for the
# header.
