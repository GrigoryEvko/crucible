# A plant of each row kind against the rule table of the repository, in a
# tree with the paths of the repository: a base file of the layer F1_rest,
# a header of the higher layer X1_wrappers and a quarantined file.  The
# enforce row of src/foundation/ with the scope include makes each include
# kind of the base file an error in the mode report: a header that no allow
# row gives, a door header and an upward include.  An allow row with `until`
# gives <vector> to the layer F0_core, so its include is a finding of the
# kind replace-pending:<vector> and no error.  In the mode report, the file
# with no plant has no finding, and a std name of the quarantined file is a
# finding and no error.  In the mode error, each plant fails the compile, and
# the file with no plant passes, so the rule table of the repository loads.
