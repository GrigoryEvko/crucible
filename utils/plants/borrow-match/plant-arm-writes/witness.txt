# An arm that the call gets by name as a closure (85) or as an object of a
# class (91), and an arm that takes its payload by value (100), are arms too.
# A call whose result is a class with a destructor is a write too: a take of
# an Option of such a payload in a cast to void (115), a replace that

# A receiver that goes through std::as_const is the same object: of a local (183), of

# of a loop (202).
# The second compile shows that a parse with no object gives the same errors.
