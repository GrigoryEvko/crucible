# A name of a sealed namespace in the include closure of a sealed root is a
# finding of the kind sealed-name.  The unit alone.cpp compiles the root alone,
# as the sentinel unit of a header does, so the closure opens the namespace
# first: a forward declaration, an opening through an inline namespace, and an
# opening before a using-directive and a namespace alias.  The unit unit.cpp
# includes the ledger first, so the closure does not open the namespace: each
# reference that a file of the closure spells is a finding, a qualified name
# from :: and a name relative to namespace crucible, and also the body of a
# macro of the closure that a different file expands.  In the mode error, each
# finding is an error.

compile forward alone.cpp
flag forward -DPLANT_FORWARD
exit forward pass
