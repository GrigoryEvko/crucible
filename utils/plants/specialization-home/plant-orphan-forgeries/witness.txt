# the authority that the template gives that type: the friend route through
# a friend declaration of niche, the key route through a hidden friend that

# family of the base.  A base file that specializes the extension point for
# a type of a different base file is an orphan too.  Each orphan is a compile
# error in each mode, and the module of the rule refuses each line.
