# A friend function template gives each of its specializations the private
# members of the class that befriends it.  A test file that specializes such
# a template with a marker, a brand or a role of its own reaches the private
# constructor of an owner, or the key that only the mint makes.  The plant
# holds the marker shape of mint_box and mint_heap_array, the branded shape of
# address_of and the key shape of mint_sole_writer.  The open mark
# does not open a function template, so a specialization of a marked friend
# template for a type of the file is a site too, and the mark gives no record.
# Each site is a compile error in each mode, and the module of the rule
# refuses each line.  Each one is also a route of the rule proof-routes.
compile forge test/forge.cpp specialization-home=on errors=forge
exit forge fail
