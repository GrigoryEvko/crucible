# No use reads a dead object, and no line names the rule view-escape: a use before
# the change, a borrow that the function takes again, a change on a path that
# returns, a move that keeps the storage, a frame that gives the owner back, a call
# by a const reference, a change of a different owner, and a call with an arena
# that keeps its blocks.  The unit blocks has a result that names a store, and not an
# element of the list that the store holds.  The unit typed_owners has owners of the
# base that keep their blocks and that hold no raw block.  In the unit inner_owners an
# owner leaves its wrapper and lives while a borrow of it is in use.  In the unit
# constructs a construct at a pointer moves an owner into an object that lives on.
# In the unit segments a SegmentList of Views keeps a borrow of an element across
# an append and across an append with code of the element.  In the unit beside one
# argument of a call gives a borrow, and a different argument names its object, but
# no callee ends it.  A callee moves the owner on and back, and gives the borrow to
# no closure.  A callee moves the owner on, and its closure holds no borrow of the
# View: a value of a call on the View that holds no borrow, a member that holds no
# borrow, a borrow of a type that cannot name an element of the View, and a borrow
# derived from a different parameter.  A derived borrow that no closure captures, a
# View that a helper reads outside a closure, and a Ref read after a lend of a
# member of its owner read live storage too.  A View read after a lend of its
# array, and a View read in the lend of a member of a different type, read no lent
# element.  In the unit through a closure argument holds a borrow through
# its captures, beside an argument that gives an object, but no callee changes the
# object of the borrow: a capture of the owner itself (31), a View of a different
# owner (38), and a callee that only reads the owner (45).  In the unit in_place a
# closure argument holds a View beside a frame door that lends no object of the View
# in place: the frame of a different array (17), and the door update, which gives the
# body a copy of the element (29).  In the unit numbers a borrow of a resource by its
# number lives beside its owner: a plain move of the owner, a generic call that moves
# the owner into its result, a read before the end, a borrow taken again, a door that
# takes the owner by a const reference, and the end of a different owner.  In the
# unit static_texts a value that holds a StaticText comes from a call with a local,
# and lives on past the end of the scope of the local (29) and past a change of it
# (36): a class of the base that states refers_static{} holds no borrow.  In the
# unit parts a change of a different part leaves a borrow of a part alone: a Record,
# a std::tuple, a std::pair and a std::array.  In the unit linear_moves a Ref of a
# linear object reads it before its move, and a Ref of an owner that is no linear
# class reads the moved-from owner.  A View of the heap block of a member of a
# linear object lives past the move, and a View of an inline array is read before
# the move.  In the unit holders a door of an owner in a Box lends its run to a
# closure that ends a different Box, and the Box ends after the door.  In the unit
# takes a View of the array that take() moves out lives while the result lives.
