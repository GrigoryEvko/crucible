# A move assignment between two objects, and a value that a call gives back
# into its object, are no self-move.  two_indices is the known miss of the
# rule: an alias through two names, which the rule reading one function at a
# time cannot see.  The same alias through two reference parameters is a move
# out of a lent parameter (plant-borrow-move-out).  A move from the object of
# an unknown pointer is no self-move, and neither is a move through a
# reference whose pointer or index changes before the move.  The move
# assignment of a session handle keeps its guard of a self-move as the
# run-time backstop of that alias (fixy/session/Handle.h).  A move out of an
# element of an array parameter, out of the object of a pointer, and through
# a reference into either, names a place that no frame of the function owns,
# so it is the kind borrow-move-out (the moves through a borrow of
# linear.cpp).  The ledger of this tree counts the five such lines, and the
# module of the rule judges the count, which holds.

flag moves -freflection
