# The object has a function of 100 KB and an executable section of 1000 KB with no symbol.  The section counts, so
# the object has 1100 KB of machine code, more than the limit 1024 KB of the kind object.  The function is less than
# the limit of the kind function, and the rule gives one error of the kind over-limit.
format 1
kind x86_64-debug-asan
compile CMakeFiles/lib.dir/wider.cpp.o src/wider.cpp functions=_Z1cv:102400 text=1024000
