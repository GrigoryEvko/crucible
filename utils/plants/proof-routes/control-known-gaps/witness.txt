# allocation with the size of a proof type in a function that is not a
# template, because GCC keeps no tree of them that the plugin can read.  This
# control pins the two gaps.  The rule parse-proof-routes refuses each shape
# on the parse tree (utils/plants/parse-proof-routes/).
