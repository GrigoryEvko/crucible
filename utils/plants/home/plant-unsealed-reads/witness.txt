# With the rule specialization-home on, a gate stays open when it reads a
# template that the rule does not seal: a function template, a template with
# the open mark, a template that a home row governs, and a crucible class
# template that the unit only declares and does not specialize.  The rule
# specialization-home reads no function template, an open mark and a row
# admit a specialization in a different file, and a different file can give
# the definition of a crucible template that the unit only declares.  A class
# template of a base root that the base only declares is sealed, because the
# rule specialization-home refuses its definition outside the base.
#
# A gate over a sealed template reads each open template that the
# definition of the sealed template reads, at each depth: through a variable
# template, a class trait, a template argument, a member alias, a consteval
# member function, an explicit specialization of a variable template and of
# a class template at its home, and a cycle of two traits.  The unit forge
# specializes the open trait in a different file, and its static assertions
# show that each such gate changes its answer.
