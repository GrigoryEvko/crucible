# The ledger of the rule use-after-move: the reviewed uses after std::move in the tests.
# A row PATH | use-after-move | N | FUNCTION: KEY | REASON admits N findings of the key KEY in the
# function FUNCTION of the file PATH.  FUNCTION is the name of the function with its namespaces, its
# classes and its parameter types.  KEY is the name or member path of the use, as the rule writes it.  The
# rule reports the first use after each move, and N counts moves, not reads.  REASON names the probe
# that the row makes, and each row gives one.  A row that admits more findings than the rule finds is
# an error.  The ledger then becomes shorter when the code changes.
# Only a test that probes a moved-from object on purpose has a row.  Each probe reads the object after
# the move to prove the state that the move gives it.  Or it uses the object to prove that the use aborts.
# A reviewer writes each row.  `python3 utils/bin/guard explain use-after-move` tells the rule.
