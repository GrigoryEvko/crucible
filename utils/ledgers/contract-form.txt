# The ledger of the rule contract-form: the files whose subject is the P2900 contract specifier itself.
# A row PATH | specifier | admit | - | REASON admits each specifier in the file PATH.  Each admitted file holds a
# specifier, so a row for a file that holds no specifier is an error, and the ledger only shrinks.  The
# rows do not admit an assumption about the values of a contract.  `python3 utils/bin/guard explain
# contract-form` tells the rule, and `python3 utils/bin/guard write --rule contract-form` writes this file.
format 1
rule contract-form
cmake/probes/contract_cache.cpp | specifier | admit | - | a probe of a compiler fix to the pre specifier, and execute_process compiles it without the plugin
test/foundation/neg/neg_contract_specifier_post.cpp | specifier | admit | - | a negative fixture of the contract rule of the plugin
test/foundation/neg/neg_contract_specifier_pre.cpp | specifier | admit | - | a negative fixture of the contract rule of the plugin
test/foundation/neg/neg_contract_specifier_template_member.cpp | specifier | admit | - | a negative fixture of the contract rule of the plugin
