# The ledger of the rule banned-calls: the sites of a banned call that wait for their migration.
# A row PATH | KIND | admit | TEXT | REASON admits the site of the ban KIND in the file PATH whose line,
# trimmed, is TEXT.  KIND is reinterpret (a reinterpret_cast), reserve (a reserve call on a std
# container), file-stream (a C++ file stream in a fixy-only directory) or spawn (a raw process spawn).
# The key is the content of the line and not its number, so an edit above the site does not move it.
# A row that matches no live site fails the rule, so the ledger shrinks with each migration.  In new
# code, a marker comment on the line, such as `// NO-RESERVE-OK: <reason>`, exempts that one line.
# `python3 utils/bin/guard explain banned-calls` tells the rule.  No command writes this file: write
# each row by hand, with its reason.
#
# The rule reads bench/ for the reserve ban.  The two reserve rows are std::vector calls in the setup
# of one bench, outside the measured region.  The quarantine plugin also reports each call, and the
# quarantine ledger holds it.
format 1
rule banned-calls
