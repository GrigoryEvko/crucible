# The ledger of the rule trait-guard: the open reads of each template that a gate of
# include/foundation, include/fixy or include/crucible reads (Family E).  A gate is a concept
# definition or a requires clause, in a header or in the check file of a header (test/layer/checks/).
# An open read names a variable template, a function template, or a class template for its value or
# its type: a translation unit can specialize each, and the specialization changes the answer of
# the gate.  A template is no file, so the PATH of each row is "-".
#
#   - | count | N | TEMPLATE | -       N reads that wait for a fix.  The count only shrinks.
#   - | count | N | TEMPLATE | REASON  the same, with the reason that the reads stay.
#   - | open | N | TEMPLATE | REASON   a template that stays open on purpose.  N is the number of
#                                      its reads, and the rule gives the row no bound.
#
# The row of a template that a gate of include/crucible reads gives a reason.  Each such read that
# a count row admits gives a warning.
#
# Run `python3 utils/bin/guard check --rule trait-guard --refresh` in the commit that removes a read.
# `python3 utils/bin/guard explain trait-guard` tells the rule.
format 1
