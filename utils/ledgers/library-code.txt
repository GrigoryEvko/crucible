# The ledger of the rule library-code: the library code of each base file in each configuration of a build.
# `python3 utils/bin/guard explain library-code` tells the rule.
#
# The records come from an RTL pass of the quarantine plugin (utils/tools/quarantine/body.cpp).  A row counts the
# places of a base file with a record of its kind and its name:
#   PATH | inlined | COUNT | NAME | -       a body of a library function that the code inlines
#   PATH | call | COUNT | NAME | -          a call of a library function
#   PATH | reference | COUNT | NAME | -     a library variable or the address of a library function
# The first configuration is the base, and a row with the prefix @NAME gives the difference of the configuration
# NAME (assay.guard.engines.plugin.counted).  A count can only fall: `python3 utils/bin/guard write --rule
# library-code --build-dir DIR` writes the rows of the configuration of a build.
