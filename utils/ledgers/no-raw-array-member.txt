# The ledger of the rule no-raw-array-member: the reviewed C array data members of include/foundation
# and include/fixy.  A row PATH | - | admit | NAME | REASON admits the member NAME in the file PATH.  A
# row whose member is gone fails the rule, so the ledger only shrinks.  Each row is a member in a file
# that another change owns, or the storage of a primitive of include/foundation/core that no lower type
# can hold.  The change that moves the member to std::array or fixy::FixedArray removes its row.
# `python3 utils/bin/guard explain no-raw-array-member` tells the rule.  No command writes this file:
# write each row by hand, with its reason.
