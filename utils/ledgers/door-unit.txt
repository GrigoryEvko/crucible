# The ledger of the rule door-unit: the doors that are headers, and the door files that include the
# Linux UAPI headers and the headers of the C library.
# A row PATH | KIND | N | ENTITY | REASON admits N findings of KIND with ENTITY in the file PATH.
# A door is one source file, so no other unit gets its system declarations.  A door file includes the
# headers of one family, because some declarations of the two families conflict.  Each reason names the
# slice of misc/01_10_2026_quarantine.md that moves the door into a source file of src/fixy/os/.
# A new finding is more than its count, and it fails.  A count above the findings of its row passes,
# and a write lowers it.  A reviewer writes each reason.  `python3 utils/bin/guard explain door-unit` tells
# the rule, and `python3 utils/bin/guard write --rule door-unit` writes this file.
format 1
rule door-unit
include/fixy/os/Socket.h | header-door | 1 | <linux/netlink.h> | the netlink socket door is in the header, so each unit that includes fixy/os/Socket.h gets the kernel declarations of netlink.  The slice Os results (4.1) moves the door into a source file of src/fixy/os/.
include/fixy/os/Socket.h | header-door | 1 | <sys/socket.h> | the socket calls of the netlink door are in the header, so each unit that includes fixy/os/Socket.h gets the socket declarations of glibc.  The slice Os results (4.1) moves the door into a source file of src/fixy/os/.
include/fixy/os/Socket.h | mixed-headers | 1 | <linux/netlink.h> and <sys/socket.h> | the door includes <linux/netlink.h> and the glibc header <sys/socket.h>.  In the slice Os results (4.1), the door moves into src/fixy/os/ and makes its socket calls with foundation::os::raw_syscall.
include/fixy/os/Time.h | header-door | 1 | <linux/ptp_clock.h> | the PTP clock door is in the header, and PtpClockReader::caps() returns ::ptp_clock_caps.  The slice Os results (4.1) gives a base record in place of the kernel struct, and moves the door into a source file of src/fixy/os/.
