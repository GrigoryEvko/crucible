# The ledger of the rule erased-brand: the sites on the erased brand DefaultBrand, one row for each file and each
# branded template.  A row PATH | erased-brand | COUNT | TEMPLATE | REASON gives the count of the sites, and the
# reason is optional.  A count can only decrease.  Where a new spelling is necessary, write the brand.  Run
# `python3 utils/bin/guard write --rule erased-brand` in the commit that removes a site.
# `python3 utils/bin/guard explain erased-brand` tells the rule and gives the branded templates.
#
# The erased brand opens no door that trusts a brand to skip a check.  mint_shared_read refuses the erased brand,
# and it asks the guard for its pool at run time.  So a site here is work to drain, and no hole.  The rows of the
# directories neg/ count the sites of the negative-compile fixtures, which no build compiles.
