# The ledger of the rule process-wide-state: the objects with static storage
# duration that are correct with one copy in each shared library.
# `python3 utils/bin/guard explain process-wide-state` tells the rule.
#
# One row is `PATH | - | admit | QUALIFIED NAME | REASON`.  A process-wide
# object carries CRUCIBLE_PROCESS_WIDE (foundation/Platform.h) and has no
# row.  The reason of a row tells why a copy in each library that compiles
# the object is correct: only one library reaches it, each copy holds the
# same value, or the object is a cache or a scratch that a second copy only
# fills again.  A reviewer writes each row by hand.
