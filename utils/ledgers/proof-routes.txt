# The ledger of the rule proof-routes: the reviewed sites of a route that can build a proof type
# with no call to its door.
# A row PATH | ROUTE | N | KEY | REASON admits N sites of the route ROUTE with the key KEY in the file
# PATH.  ROUTE is union, pointer-cast, allocator, raw-allocation, explicit-instantiation,
# function-specialization, member-pointer-specialization or friend-template-specialization.  KEY is
# the key that the rule prints.  REASON tells why the site builds no proof type, and each row gives
# one.  A row above the count of sites in the tree is stale, and the rule refuses it, so the ledger
# only becomes shorter.
# A reviewer writes each row.  `python3 utils/bin/guard explain proof-routes` tells the rule.
