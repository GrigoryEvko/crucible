# The ledger of the rule mint-pattern: the reviewed admissions of a mint that
# does not meet an axis of section XXI of CLAUDE.md.  `python3 utils/bin/guard
# explain mint-pattern` tells the rule.  A reviewer writes each row.
#
# One row is `PATH | KIND | admit | ENTITY | REASON`.  The kind is the axis
# that the mint does not meet, such as mint-not-constexpr.  The entity is the
# qualified name of the mint with the types of its parameters.  PATH is the
# file of the record of the mint with its body.  A row names no line, and a
# change that only moves the mint keeps the row.
#
# The reason says why the mint keeps its shape.  Section XXI drops constexpr
# from a mint that allocates, and from a mint that reads runtime state, such
# as an atomic, a thread identity or a system call.  -Winvalid-constexpr
# refuses constexpr on a function that can never be constant evaluated.  A row
# that admits no finding fails the rule, and the file only shrinks while the
# tree stays the same.
