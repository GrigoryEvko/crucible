# The ledger of the rule syscalls: the raw system calls of each file and entity, counted.
#   PATH | raw-syscall | N | HOLDER: SHAPE | CLAIM
#       N calls of the system call SHAPE in HOLDER.  HOLDER is a function with the types of its
#       parameters, "macro NAME" or namespace-scope, and SHAPE is the name of a function of the C
#       library, or syscall(SYS_NAME).  CLAIM is the effects::* capability claim of the calls, and a
#       row with no claim is an error
# One set of rows judges each build.  N is the largest count over the configurations of the landing
# gate, so the set also holds the row of an arm that only one build kind compiles.
# No row admits a finding of the kinds outside-door and denied-syscall, or a difference of a grant
# set.  Each count only falls.
# `python3 utils/bin/guard explain syscalls` tells the rule.  A landing that builds each
# configuration of the gate writes the lower count into this file.
