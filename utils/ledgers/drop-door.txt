# The ledger of the rule drop-door.  `python3 utils/bin/guard explain drop-door` tells the rule and its policy,
# and `python3 utils/bin/guard write --rule drop-door` writes this file.
format 1
rule drop-door
reason bench/ | the measured loop of a bench steps a session handle that holds a token, and it assigns the next handle over the handle that the step consumed
reason include/fixy/concurrent/ | the fork writes the token of a child into the frame of that child
reason include/fixy/session/ | the hold of a session writes a token back through a reference after a read
reason include/foundation/core/ | the alternatives of Option and Result end the lifetime of a payload, and the cursor of an Option writes its slot
reason include/foundation/permissions/ | the inline fork writes a child token back through a reference, and the pool of shared permissions writes its parked token
reason test/ | the tests write a token back through a reference in a door body, and the shape probes compare a write of a token with its raw form
bench/ | untracked-assignment | 1 | - | -
include/fixy/concurrent/ | untracked-assignment | 20 | - | the fork writes the token of a child into the frame of that child.  The entity names the token type, so each child tag of a fork in the tests is its own line
include/fixy/session/ | untracked-assignment | 5 | - | the hold of a session writes a read loan back through a reference after a read.  The entity names the loan type, so each region of a hold in the tests is its own line
include/foundation/core/ | destroy | 150 | - | the alternatives of Option and Result end the lifetime of a payload, and in a test build the consume tracker gives the end of a Linear a destructor.  The entity names the payload type, so each payload type of an Option or a Result in the tests, the benches and the fuzz harnesses is its own line, such as each channel handle and each refused start of a thread door
include/foundation/permissions/ | untracked-assignment | 14 | - | the pool of shared permissions writes its parked token on a deposit.  The entity names the token type, so each tag of a pool in the tests and the benches is its own line
test/foundation/ | untracked-assignment | 1 | - | -
