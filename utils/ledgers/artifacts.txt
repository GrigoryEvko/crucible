# The ledger of the rule artifacts: the link facts of the programs, the shared libraries and the modules of the
# target all, for each group.  `python3 utils/bin/guard explain artifacts` tells the rule, and the head comment of
# utils/assay/guard/engines/elf/artifacts.py gives the rules.
#
# The ledger holds one set of rows for each build, and no configuration row.  Each build is judged against the
# full set.  No row admits a missing hardening property or a run path directory that the host does not give.
#
# A fact row:  @build/GROUP | KIND | 1 | ENTITY | -
#   An artifact of the group GROUP gives the fact KIND ENTITY: a needed library, a directory of the run path, or
#   an archive member from outside the build directory.  The first directory of the source directory of the
#   target gives the group: vessel, benches, tests, or tools.
#
# A new fact fails the test.  A row whose fact goes passes.  A write keeps each row, and it adds the rows of the
# build:
#   python3 utils/bin/guard write --rule artifacts --build-dir build
# The write refuses a new fact without --raise.  The head comment of the rule gives the reasons for --raise.
format 1
