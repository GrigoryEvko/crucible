# The ledger of the rule heavy-include: the includes of heavy headers outside the source root by the
# files under include/, in each configuration of a build.  `python3 utils/bin/guard explain heavy-include`
# tells the rule.
#
# A header that each translation unit compiles must not include a heavy header for one function.  The
# heavy and light rows of utils/rule-table.txt give the cost of each header.  A header is heavy when it
# costs more than <meta> times the factor of the measured rule heavy-include of utils/registry.txt.
#
# The rows of assay.core.ledger with the policy count, and the configurations of
# assay.guard.engines.plugin.counted:
#   PATH | heavy-include | COUNT | <header> | -
#     The includes that the base configuration holds today.  Each run gives a warning for the row.  When
#     you remove the include, run python3 utils/bin/guard write --rule heavy-include --build-dir DIR in
#     the same commit.
#   PATH | heavy-include | COUNT | <header> | REASON
#     A header that owns a heavy header on purpose, for example the one door of a system facility.  The
#     reason makes the row a keep row, and the row gives no warning.
#   @NAME | PATH | heavy-include | DELTA | <header> | -
#     The difference of the configuration NAME from the base count.
format 1
