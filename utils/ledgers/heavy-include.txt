# The ledger of the rule heavy-include: the includes of heavy headers outside the source root by the
# files under include/.  `python3 utils/bin/guard explain heavy-include` tells the rule.
#
# A header that each translation unit compiles must not include a heavy header for one function.  The
# heavy and light rows of utils/rule-table.txt give the cost of each header.  A header is heavy when it
# costs more than <meta> times the factor of the measured rule heavy-include of utils/registry.txt.
#
# The rows of assay.core.ledger with the policy count (assay.guard.engines.plugin.counted).  One set of
# rows judges each build, and the count of a key is its largest count over the configurations of the
# landing gate:
#   PATH | heavy-include | COUNT | <header> | -
#     The includes that the tree holds today.  A landing that builds each configuration of the gate
#     lowers the row when the include goes.
#   PATH | heavy-include | COUNT | <header> | REASON
#     A header that owns a heavy header on purpose, for example the one door of a system facility.  The
#     reason makes the row a keep row.
# A row gives no output, with a reason or with none.
format 1
rule heavy-include
