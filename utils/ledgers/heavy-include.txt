# The ledger of the rule heavy-include: the includes of heavy standard headers in the headers
# under include/.  `python3 utils/bin/guard explain heavy-include` tells the rule.
#
# A header that each translation unit compiles must not include a heavy header for one function.
# utils/scripts/header-costs.txt gives the cost of each header.  A header is heavy when it costs
# more than <meta> times the factor of the measured rule heavy-include of utils/registry.txt.
#
# A count row:  PATH | - | 1 | <header> | -
#   An include that the tree holds today.  Each run gives a warning for it.  When you remove the
#   include, run python3 utils/bin/guard check --rule heavy-include --write in the same commit.
#
# A keep row:   PATH | - | 1 | <header> | REASON
#   A header that owns a heavy header on purpose, for example the one door of a system facility.
#   The reason makes the row a keep row, and the row gives no warning.
