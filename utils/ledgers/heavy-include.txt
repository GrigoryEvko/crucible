# The ledger of the rule heavy-include: the includes of heavy headers outside the source root by the
# files under include/.  `python3 utils/bin/guard explain heavy-include` tells the rule.
#
# A header that each translation unit compiles must not include a heavy header for one function.  The
# heavy and light rows of utils/rule-table.txt give the cost of each header.  A header is heavy when it
# costs more than <meta> times the factor of the measured rule heavy-include of utils/registry.txt.
#
# The rows of assay.core.ledger with the policy count (assay.guard.engines.plugin.counted).  One set of
# rows judges each build, and the count of a key is its largest count over the configurations of the
# landing gate:
#   PATH | heavy-include | COUNT | <header> | -
#     The includes that the tree holds today.  A landing that builds each configuration of the gate
#     lowers the row when the include goes.
#   PATH | heavy-include | COUNT | <header> | REASON
#     A header that owns a heavy header on purpose, for example the one door of a system facility.  The
#     reason makes the row a keep row.
# A row gives no output, with a reason or with none.
format 1
rule heavy-include
include/crucible/BackgroundThread.h | heavy-include | 1 | <memory> | the class holds its stage pipeline in a std::unique_ptr, and run_on_publish_stage takes the address of the job with std::addressof
include/crucible/Cipher.h | heavy-include | 1 | <filesystem> | the store makes its object directory with std::filesystem::create_directories, and it makes the path of HEAD with the operator / of std::filesystem::path
include/crucible/Serialize.h | heavy-include | 1 | <memory> | the reader makes the variant counter of a node with std::construct_at, because the counter refuses a step to the value 0 that a file can hold
include/crucible/cntp/Fec.h | heavy-include | 1 | <arm_neon.h> | -
include/fixy/Borrowed.h | heavy-include | 1 | <ranges> | the constructors from a range accept only a std::ranges::contiguous_range that is a std::ranges::borrowed_range, and they read std::ranges::data and std::ranges::size
include/fixy/Budgeted.h | heavy-include | 1 | <memory> | a moved-from source gets the unbounded grade again through std::destroy_at and std::construct_at, because Graded sets its grade only when it makes the object
include/fixy/EpochVersioned.h | heavy-include | 1 | <memory> | a moved-from source gets the genesis version again through std::destroy_at and std::construct_at, because Graded sets its grade only when it makes the object
include/fixy/SelfContained.h | heavy-include | 1 | <ranges> | the predicates of a self-contained type read std::ranges::range, view, borrowed_range and range_value_t, and the walk of a range reads std::ranges::begin and end
