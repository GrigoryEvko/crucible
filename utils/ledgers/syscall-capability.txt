# The ledger of the rule syscall-capability: the raw system calls of each file and entity, counted.
#   PATH | raw-syscall | N | HOLDER: SHAPE | CLAIM
#       N calls of the system call SHAPE in HOLDER.  HOLDER is a function with the types of its
#       parameters, "macro NAME" or namespace-scope, and SHAPE is the name of a function of the C
#       library, or syscall(SYS_NAME).  CLAIM is the effects::* capability claim of the calls, and a
#       row with no claim is an error
# No row admits a finding of the kind outside-door.  Each count only falls.
# `python3 utils/bin/guard explain syscall-capability` tells the rule, and
# `python3 utils/bin/guard write --rule syscall-capability --build-dir DIR` writes this file in the
# commit that lowers a count.
