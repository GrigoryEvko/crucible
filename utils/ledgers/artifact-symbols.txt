# The ledger of the rule artifact-symbols: the libstdc++ symbols and the C runtime symbols of the libraries
# foundation, fixy and crucible for each build kind, and the throws and the polymorphic classes of the static
# libraries of the tree that the tree cannot remove.  `python3 utils/bin/guard explain artifact-symbols` tells
# the rule, and the head comment of utils/assay/guard/engines/elf/artifact_symbols.py gives the rules.
#
# The configuration rows of a kind:  configuration KIND kind KIND  and  configuration KIND tier TIER
#   The ledger holds the symbols of the build kind KIND (BUILD_DIR/build-kind.txt) on the target tier TIER
#   of utils/assay/core/target.py.  The first configuration is the base.  A build of a kind or a tier that
#   the ledger does not hold prints its rows, and `guard write --rule artifact-symbols --import LOG` puts
#   them here.
#
# A symbol row of the base:  @build/LIBRARY | MARK | 1 | SYMBOL | -
#   An object of the archive LIBRARY has an undefined reference to SYMBOL, and the libstdc++ of the
#   compiler defines it.  MARK is allow for a symbol of the allowlist of plan section 13.4, and ratchet for
#   each other symbol.  At the S4 gate, no ratchet row can stay.
#   A C runtime symbol has the MARK libc-allow or libc-ratchet: libstdc++ does not export it, and a file of
#   the C runtime of the compiler defines it.  libc-allow marks a call that GCC makes itself, a function of
#   the support library of GCC, and a call of glibc that a door of fixy keeps (rule R5).  At the S4 gate,
#   libfixy.a holds no libc-ratchet row.
# A difference row of another kind:  @KIND | @build/LIBRARY | MARK | +1 | SYMBOL | -
#
# A row of no configuration:  @build/ARCHIVE | throw | admit | TEXT | REASON
#                         and  @build/ARCHIVE | vtable | admit | TEXT | REASON
#   The row admits a throw in a function, or a typeinfo and a vtable of a class, of the archive when the
#   demangled name holds TEXT, in each build.  A person writes such a row with its reason.
#
# A new symbol fails the test.  A row whose symbol goes fails too, until the same commit writes the rows
# of the kind again:
#   python3 utils/bin/guard write --rule artifact-symbols --build-dir build
# The write refuses a new ratchet or libc-ratchet symbol.  The head comment of the rule gives the reasons for
# --raise.
