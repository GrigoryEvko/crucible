# The ledger of the rule artifact-symbols: the imports of each static library of the root for each build kind,
# and the throws and the polymorphic classes of these libraries that the tree cannot remove.
# `python3 utils/bin/guard explain artifact-symbols` tells the rule, and the head comment of
# utils/assay/guard/engines/elf/artifact_symbols.py gives the rules.
#
# The configuration rows of a kind:  configuration KIND kind KIND  and  configuration KIND tier TIER
#   The ledger holds the imports of the build kind KIND (BUILD_DIR/build-kind.txt) on the target tier TIER
#   of utils/assay/core/target.py.  The first configuration is the base.  The largest count of each key
#   over the configurations judges a build of a kind that the ledger does not hold.  Such a build prints
#   its rows, and `guard write --rule artifact-symbols --import LOG` or `--add-configuration` puts them
#   here.
#
# An import row of the base:  @build/LIBRARY | MARK | 1 | IMPORT | -
#   An object of the archive LIBRARY references a name that no library of the root defines, and a provider
#   defines it.  IMPORT is SYMBOL@VERSION for an import of a shared library, with the default version of
#   the name, and the name alone for an import of an archive or of a start file.  MARK gives the family of
#   the provider:
#     allow, ratchet            libstdc++.so of the compiler.  allow marks the allowlist of plan section 13.4
#     libc-allow, libc-ratchet  a file of the runtime of the compiler.  libc-allow marks a call that GCC
#                               makes itself, a function of the support library of GCC, and a call of glibc
#                               that a door of fixy keeps (rule R5)
#     static-ratchet            an archive of a link line of the build
#     crt-allow, crt-ratchet    a start file or an end file.  crt-allow marks __dso_handle beside an
#                               allowed __cxa_atexit
#     host-ratchet              a shared library of a link line of the build, such as libbpf.so
#   At the S4 gate, no ratchet row can stay, and libfixy.a holds no libc-ratchet row.
# A difference row of another kind:  @KIND | @build/LIBRARY | MARK | +1 | IMPORT | -
#
# A row of no configuration:  @build/ARCHIVE | throw | admit | TEXT | REASON
#                         and  @build/ARCHIVE | vtable | admit | TEXT | REASON
#   The row admits a throw in a function, or a typeinfo and a vtable of a class, of the archive when the
#   demangled name holds TEXT, in each build.  A person writes such a row with its reason.  In the base
#   archives libfoundation.a and libfixy.a, a reference to a throw helper of libstdc++, such as
#   std::__throw_length_error, is a throw too.
# A throw helper row of an archive outside the base:  @build/ARCHIVE | helper-throw | COUNT | HELPER | -
#   The archive has COUNT live references to the throw helper HELPER of libstdc++.  A difference row of
#   another kind gives its difference.  The count can only fall.
#
# A new import fails the test, and so does an import with no provider.  A row whose import goes fails too,
# until the same commit writes the rows of the kind again:
#   python3 utils/bin/guard write --rule artifact-symbols --build-dir build
# The write refuses a new import with a ratchet mark and a count of helper-throw above its row.  The head
# comment of the rule gives the reasons for --raise.
