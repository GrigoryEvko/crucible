# The ledger of the rule artifact-symbols: the imports of each static library of the root, and the throws and the
# polymorphic classes of these libraries that the tree cannot remove.  `python3 utils/bin/guard explain
# artifact-symbols` tells the rule, and the head comment of utils/assay/guard/engines/elf/artifact_symbols.py gives
# the rules.
#
# The ledger holds one set of rows for each build, and no configuration row.  A Debug build, a Release build and a
# build with a sanitizer give other imports, and the set holds the imports of each of them.  Each build is judged
# against the full set.
#
# An import row:  @build/LIBRARY | MARK | 1 | IMPORT | -
#   An object of the archive LIBRARY references the name IMPORT, which no library of the root defines and a
#   provider defines.  IMPORT has no version, because a version changes with the C library of the host.  MARK
#   gives the family of the provider:
#     allow, ratchet            libstdc++.so of the compiler.  allow marks the allowlist of plan section 13.4
#     libc-allow, libc-ratchet  a file of the runtime of the compiler.  libc-allow marks a call that GCC
#                               makes itself, a function of the support library of GCC, and a call of glibc
#                               that a door of the base keeps, from the member of its door (rule R5)
#     door-ratchet              a file of the runtime of the compiler: a call of glibc that a door of the base
#                               keeps, from a member that is not its door.  A person writes the row, with the
#                               code of the call and the slice of the plan that moves it as its reason
#     static-ratchet            an archive of a link line of the build
#     crt-allow, crt-ratchet    a start file or an end file.  crt-allow marks __dso_handle beside an
#                               allowed __cxa_atexit
#     host-ratchet              a shared library of a link line of the build, such as libbpf.so
#   At the S4 gate, no ratchet row can stay, and libfixy.a holds no libc-ratchet row.
#
# A throw row:  @build/ARCHIVE | throw | admit | TEXT | REASON
#         and   @build/ARCHIVE | vtable | admit | TEXT | REASON
#   The row admits a throw in a function, or a typeinfo and a vtable of a class, of the archive when the
#   demangled name holds TEXT, in each build.  A person writes such a row with its reason.  In the base
#   archives libfoundation.a and libfixy.a, a reference to a throw helper of libstdc++, such as
#   std::__throw_length_error, is a throw too.
# A throw helper row of an archive outside the base:  @build/ARCHIVE | helper-throw | COUNT | HELPER | -
#   The largest count of the live references of the archive to the throw helper HELPER of libstdc++ in the
#   builds.  The count can only fall.
#
# A new import fails the test, and so does an import with no provider.  A row whose import goes passes, and a
# row throw or vtable that admits nothing passes too.  A write keeps each row, and it adds the rows of the
# build:
#   python3 utils/bin/guard write --rule artifact-symbols --build-dir build
# The write refuses a new import with a ratchet mark and a count of helper-throw above its row.  The head
# comment of the rule gives the reasons for --raise.  The write refuses a new import door-ratchet also with --raise.
format 1
