# The ledger of the rule instruction-total: the baseline of the user instructions of the compiles of a build
# of the configuration x86_64-debug-asan, the build of the preset default.
# `python3 utils/bin/guard explain instruction-total` tells the rule, and
# `python3 utils/bin/guard write --rule instruction-total --build-dir BUILD` writes the two rows again from a
# build of that configuration.  The rule does not apply to a build of a different configuration.
#
# The two rows:
#   - | x86_64-debug-asan | INSTRUCTIONS | objects | REASON
#   - | x86_64-debug-asan | INSTRUCTIONS | fixtures | REASON
#   The sum, over each object of the target all and over each negative fixture, of the user instructions
#   of the compile that made it, at the last write.  The record of a ccache hit keeps the count of the
#   compile that made its object, from the cost store of utils/assay/core/cost_store.py.  A result of the
#   store of the fixture driver keeps the count of the compile that made it.  A direct compile and a
#   ccache miss give the same count (utils/assay/core/meter.py, A COMPILE THROUGH CCACHE).
#
# A growth over the limit of the measured rule instruction-total of utils/registry.txt gives an error.  A
# total less than the baseline gives no finding, and a write with no reason lowers the baseline.  The count
# covers the template instantiation and the constant evaluation.  To accept a growth, raise the baseline in
# the same commit with a reason:
#   python3 utils/bin/guard write --rule instruction-total --build-dir build --reason TEXT
