# The ledger of the rule detail-namespace: the test files that can use a detail namespace of
# foundation or fixy.
# A row PATH | detail-use | N | HOLDER: NAMESPACE | REASON admits N uses of the detail namespace
# NAMESPACE, for example foundation::effects::detail, in the file PATH.  HOLDER is the function that
# holds the use, with the types of its parameters, "macro NAME" for a use that a macro body spells, or
# namespace-scope.  Only a file under test/ and outside test/fuzz/ can have a row, also a file that the
# build writes under test/ of the build directory, and each row gives a reason.  A count above its row
# fails, and a row that admits more uses than the code has is stale, so the ledger only becomes
# shorter.  A test that can get the same fact through the public door of the base must use the door,
# and its row goes.
# A reviewer writes each reason.  `python3 utils/bin/guard explain detail-namespace` tells the rule.
