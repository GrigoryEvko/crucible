# The ledger of the rule detail-namespace: the test files that can use a detail namespace of
# foundation or fixy.
# A row PATH | - | N | NAMESPACE | REASON admits N uses of the detail namespace NAMESPACE, for example
# ::foundation::effects::detail, in the file PATH.  Only a file under test/ and outside test/fuzz/ can
# have a row, and each row gives a reason.  A file with more uses than its row admits fails, and a row
# that admits more uses than the file has is stale, so the ledger only becomes shorter.  A test that
# can get the same fact through the public door of the layer must use the door, and its row goes.
# A reviewer writes each row.  `python3 utils/bin/guard explain detail-namespace` tells the rule.
