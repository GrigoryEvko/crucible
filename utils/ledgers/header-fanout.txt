# `python3 utils/bin/guard write --rule header-fanout --build-dir BUILD` writes the rows of one

#
# The facts of a configuration:
#   configuration NAME KEY VALUE
#   The build kind, the target tier and each cache variable that changes the objects of all, as the
#   configuration rows of utils/ledgers/quarantine.txt.  A build with other facts has no baseline here.
#   The KIND cell of each row that follows holds the NAME of a configuration.
#
# A row:  HEADER | KIND | ALONE BYTES/READERS | - | -
#   ALONE BYTES  the bytes that the sentinel of the header in test/layer includes after its source
#   READERS      the objects of the target all and the negative fixtures that read the header
#

# threshold of the measured rule header-fanout of utils/registry.txt, give a warning.  To accept the cost,
