# The ledger of the rule padded-list: the fixed lists whose element type has a padding bit.
# `python3 utils/bin/guard explain padded-list` tells the rule.
#
# With -ftrivial-auto-var-init=zero, GCC writes one store for each padding hole of each element of
# a fixed list in an automatic object, with no loop.  Make each padding byte a member.  The measured
# rule padded-list of utils/registry.txt gives the element count above which a list counts.
#
# The rows of assay.core.ledger with the policy count:
#   PATH | KIND | 1 | DECLARATION: ELEMENT | -
#     A padded list that the tree holds today.  Each run gives a warning for its file.  When you
#     remove the padding, run python3 utils/bin/guard write --rule padded-list --build-dir DIR in the
#     same commit.
#   PATH | KIND | 1 | DECLARATION: ELEMENT | REASON
#     An element type with padding on purpose.  The reason makes the row a keep row, and the warning
#     of its file gives the reason.
#
# The kind is padded-alias, padded-member, padded-return or padded-parameter.  DECLARATION and
# ELEMENT are the spellings of GCC that the quarantine plugin gives
# (utils/tools/quarantine/declaration.cpp, THE RULE padded-list).
format 1
rule padded-list

include/fixy/session/Watch.h | padded-member | 1 | fixy::session::watch::detail::registry::threads: fixy::session::watch::detail::thread_record | each record is alignas(64) and fills one cache line, so two threads that write two records never share a line. The registry has static storage
