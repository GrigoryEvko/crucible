# The objects with static storage duration that are correct with one copy in
# each shared library.  utils/scripts/check-process-wide-state.py reads this file.
#
# One row:  path | qualified name | reason
#
# A process-wide object carries CRUCIBLE_PROCESS_WIDE (foundation/Platform.h)
# and has no row.  A row gives the reason why a copy in each library that
# compiles the object is correct: only one library reaches it, each copy holds
# the same value, or the object is a cache or scratch that a second copy only
# fills again.
