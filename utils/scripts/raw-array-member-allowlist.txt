# C array data members that utils/scripts/check-no-raw-array-member.py admits.
#
# One line per member: `path name reason`.  An entry whose member is gone
# fails the gate, so this list only shrinks.  Each entry here is a member in a
# file that another change owns at the time of writing, or the storage of a
# primitive of include/foundation/core that no lower type can hold.  The
# change that moves the member to std::array or fixy::FixedArray deletes its
# line in the same commit.
include/foundation/core/Scalar.h bytes the bytes that decode checks before a value exists: foundation/core has no fixed array below it, std::array is outside the header allowance of the base, and each read is at an offset of a part of the type, inside its size
include/foundation/core/Scalar.h sorted the sorted values of the enumerators of an enumeration: foundation/core has no fixed array below it, std::array is outside the header allowance of the base, and the search reads only the first count values
include/foundation/core/Text.h bytes_ the buffer of FixedText: foundation/core has no fixed array below it, std::array is outside the header allowance of the base, and the count of the buffer never reads past it
