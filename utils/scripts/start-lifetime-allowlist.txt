# start-lifetime-allowlist — the reviewed uses of std::start_lifetime_as
# and std::start_lifetime_as_array.  utils/scripts/check-start-lifetime.py reads
# this file.
#
# Format: path:key, or path:key xN.  The key is the name and its template
# argument list, with the white space reduced, as the guard prints it.
# An entry admits exactly one use in that file with that key, or N uses
# with the suffix.  A line that starts with '#' is a comment, and each
# entry has one above it.
#
# An entry can name two places only: the checked start in
# include/foundation/Lifetime.h and a negative fixture.  The guard refuses
# an entry for any other path.  New
# code calls foundation::lifetime::start_as_array, which refuses a proof
# subobject at compile time, and needs no entry.

# The checked start.  T is a template parameter, and the function requires
# ImplicitLifetimeThroughout<T>: T and each subobject of T at each depth is
# an implicit-lifetime type.
