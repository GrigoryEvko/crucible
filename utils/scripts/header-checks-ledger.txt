# utils/scripts/header-checks-ledger.txt — the compile-time work that each header under include/
# still does in each translation unit that includes it.  utils/scripts/check-header-checks.py
# reads this ledger.
#
# A header holds no self-test namespace, no static_assert at namespace scope and no static_assert
# in the body of a function that is not a template.  Such a check belongs in the check file of the
# header, which one translation unit compiles one time: test/layer/checks/<layer>/<path>.cpp for
# include/<layer>/<path>.h.  The first line of code of a check file includes its header.  A
# reflection walk outside each template is lazy: a variable template, or a member of a template.
#
# A count row:  path | self-test namespaces | namespace-scope static_asserts
#               function static_assert | path | count
#               eager evaluation | path | count
#   Each item of a row gives a warning on each run.  The counts can only decrease.  A header with no
#   item of a kind has no row of that kind.  When you move a check or make an evaluation lazy, run
#   python3 utils/scripts/check-header-checks.py --write in the same commit.
#
# A keep row:   keep | path | kind | key | reason
#   One item that stays in its header, because its result depends on the translation unit that
#   includes the header.  The kind is namespace, static_assert, function static_assert or eager
#   evaluation.  The key is the one that --list prints.  The reason is mandatory.
