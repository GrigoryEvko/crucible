# utils/scripts/header-checks-ledger.txt — the compile-time checks that each header under include/
# still holds.  utils/scripts/check-header-checks.py reads this ledger.
#
# A header holds no self-test namespace and no static_assert at namespace scope.  Such a check
# runs again in each translation unit that includes the header.  It belongs in the check file of
# the header, which one translation unit compiles one time: test/layer/checks/<layer>/<path>.cpp
# for include/<layer>/<path>.h.  The first line of code of a check file includes its header.
#
# A count row:  path | self-test namespaces | namespace-scope static_asserts
#   The counts can only decrease.  A header with no check has no row.  When you move a check, run
#   python3 utils/scripts/check-header-checks.py --write in the same commit.
#
# A keep row:   keep | path | namespace or static_assert | key | reason
#   One check that stays in its header, because its result depends on the translation unit that
#   includes the header.  The key of a namespace is its full name.  The key of a static_assert is
#   the spelling of its condition, as --list prints it.  The reason is mandatory.
