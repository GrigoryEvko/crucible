# utils/scripts/no-throw-no-rtti-allowlist.txt — the throws and the polymorphic classes that
# utils/scripts/check-no-throw-no-rtti.sh admits in an artifact.  One row each:
#
#   throw  | <artifact file name> | <text of the function name> | <reason>
#   vtable | <artifact file name> | <text of the class name>    | <reason>
#
# A row matches when the demangled name of the function or the class holds its text.  A row
# whose artifact the run scans and that matches nothing is stale and fails, so the list only
# shrinks.  A reason holds no `|`.  A throw of std::bad_alloc or std::bad_array_new_length,
# the failure of an allocation inside libstdc++, needs no row.
