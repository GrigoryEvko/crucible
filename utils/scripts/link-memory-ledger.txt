# utils/scripts/link-memory-ledger.txt — the links that can take more peak memory than the error
# threshold of link-memory (utils/scripts/budgets.txt).  utils/scripts/build-launcher.py fails a link
# over that threshold unless a row of this ledger admits its output for the kind of the build.
# utils/scripts/check-compile-cost.py reads the ledger too.
#
# A row:  kind | output | GB | reason
#   kind     the build kind of BUILD_DIR/build-kind.txt, for example x86_64-debug-asan
#   output   the executable or the shared library, relative to the build directory
#   GB       the peak resident memory at the last --write, in GB of 2^30 bytes
#   reason   why the link can take that memory.  A row needs a reason
#
# A link over the error threshold that a row admits gives a warning, and the link does not fail.  In a
# build of its kind, the check gives a warning for a row while its output stays over the error
# threshold, and an error when the output is at or under it.  python3 utils/scripts/check-compile-cost.py
# --check link-memory --build-dir DIR --write [--reason TEXT] writes the rows of the kind of a build
# again from that build.
