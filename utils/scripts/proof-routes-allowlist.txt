# proof-routes-allowlist.txt: the reviewed sites that utils/scripts/check-proof-routes.py admits.
#
# Format: path:rule:key, or path:rule:key xN for N sites.  The key is the
# one the guard prints.  Each paragraph starts with a comment that gives
# the reason.  An entry above the count that the tree has is stale, and
# the guard refuses it, so the list only shrinks.

# Unions of scalars.  The permission-tag tests need a union type to prove
# that a union is not a permission tag, and the self-contained walk needs
# two to prove that it reads a union member.  No member is a proof type.

test/layer/checks/fixy/SelfContained.cpp:union:EitherPointer
test/layer/checks/fixy/SelfContained.cpp:union:EitherValue

# Unions of scalars in the stable-id tests.  GCC prints a union value
# without its active member, so the stable id refuses a union value.  These
# unions prove that refusal.  No member is a proof type.
test/foundation/test_identity_attacks.cpp:union:Either
test/layer/checks/foundation/reflect/Hash.cpp:union:Either

# Probe unions of the checked lifetime start.  Each one is local to a

test/layer/checks/foundation/Lifetime.cpp:union:ProofOrByte
