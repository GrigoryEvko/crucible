# utils/scripts/header-alone-ledger.txt — the headers of include/ that can include more bytes alone
# than the error threshold of the row of their layer (header-alone-foundation, header-alone-fixy or
# header-alone-crucible in utils/scripts/budgets.txt).  utils/scripts/check-compile-cost.py reads it.
#
# A row:  kind | header | MB | reason
#   kind     the build kind of BUILD_DIR/build-kind.txt, for example x86_64-debug-asan.  The bytes of
#            a header alone depend on the kind: with -march=native, a header that selects intrinsics
#            includes <immintrin.h> too
#   header   the header, relative to the repository root
#   MB       the bytes that it includes alone at the last --write, in MB of 2^20 bytes
#   reason   why the header can include that much.  A row needs a reason
#
# In a build of its kind, a row gives a warning while its header stays over the error threshold, and
# an error when the header is at or under it.  python3 utils/scripts/check-compile-cost.py --check
# header-alone --build-dir DIR --ninja ninja --write [--reason TEXT] writes the rows of the kind of a
# build again from that build.
