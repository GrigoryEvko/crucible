# utils/scripts/test-time-ledger.txt — the tests that take more wall time than the error threshold of
# the row test-time of utils/scripts/budgets.txt, for one kind of build.
# utils/scripts/test-launcher.py reads it after each executable test, and
# utils/scripts/check-test-time.py reads it for the other tests of a ctest run.
#
# A row:  kind | test | value | reason
#
# The kind is the line of BUILD_DIR/build-kind.txt, for example x86_64-debug-asan.  The value is the
# measured wall time in seconds.  A test with a row gives a warning, so the debt stays visible.  A test
# with a row whose wall time is at or below the error threshold fails.  Remove the row in the commit
# that makes the test fast.
