# utils/scripts/function-size-ledger.txt — the objects whose largest function can be larger than the
# error threshold of the measured rule function-size (utils/registry.txt).
# utils/assay/guard/legacy/check_compile_cost.py reads it.
#
# A row:  kind | object | KB | reason
#   kind     the build kind of BUILD_DIR/build-kind.txt, for example x86_64-debug-asan
#   object   the object, relative to the build directory
#   KB       the size of its largest function at the last --write
#   reason   why the function can have that size.  A row needs a reason
#
# In a build of its kind, a row gives a warning while its object stays over the error threshold, and
# an error when the object is at or under it.  python3 utils/bin/guard check --rule function-size
# --build-dir DIR --write [--reason TEXT] writes the rows of the kind of a build again from that build.
