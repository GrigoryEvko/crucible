# detail-namespace-allowlist — the test files that may use a detail namespace
# of foundation or fixy, read by utils/scripts/check-detail-namespace.py.
#
# A row is PATH NAMESPACE xN — REASON.  NAMESPACE is the detail namespace,
# N the number of uses in the file.  Only a file under test/ may take a row.
# A file with more uses than its row admits fails, and a row that admits
# more uses than the file has is stale, so the list only shrinks.  A test
# that can reach the same fact through the public door of the layer must use
# the door and leave the list.
