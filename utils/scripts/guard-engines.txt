# The engine of each script, which the rule guard-engines (`guard check --rule guard-engines`) holds to the code.
#
# One row for each script:  path | engine[,engine...] | the input that is not C++ source
#
# An engine is how the script decides a fact.  tsast is the parse tree of
# utils/assay/readers/tsast.py, and preprocessor is the store of utils/assay/guard/preprocessed.py.
# compiler, json, cmake-api (the CMake file API), python-ast, ast-grep-bash and
# git are the other engines.  text is input that is not C++ source, such as an
# allowlist or compiler output.  A text row must name that input in the third
# cell.  none marks a script that decides no fact.  kit marks a module that
# implements an engine, and the code rules do not read it.
