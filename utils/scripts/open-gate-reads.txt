# utils/scripts/open-gate-reads.txt — the open reads of each template that a gate of
# include/foundation, include/fixy or include/crucible reads, read by
# utils/scripts/check-trait-injection.py (Family E).  A gate is a concept definition or a
# requires clause, in a header or in the check file of a header (test/layer/checks/).  An
# open read names a variable template, a function template, or a class template for its
# value or its type: a translation unit can specialize each, and the specialization
# changes the answer of the gate.
#
#   <template> | <count>             reads that wait for a fix.  The count only shrinks.
#   <template> | <count> | <reason>  the same, with the reason that the reads stay.
#   <template> | open | <reason>     a template that stays open on purpose.
#
# The row of a template that a gate of include/crucible reads gives a reason.  Each such
# read that a count row admits gives a warning.
#
# Run check-trait-injection.py --refresh in the commit that removes a read.
