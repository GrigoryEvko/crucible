# a fixed list in an automatic object, with no loop.  Make each padding byte a member.  The row

#   A padded list that the tree holds today.  Each run gives a warning for it.  When you remove the
#   padding, run python3 utils/scripts/check-padded-lists.py --build-dir BUILD_DIR --write in the
#   same commit.
#
# A keep row:   keep | path | role | declaration | element type | reason
#   An element type with padding on purpose.  The reason is mandatory.
