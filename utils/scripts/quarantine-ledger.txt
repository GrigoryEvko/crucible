# utils/scripts/quarantine-ledger.txt — the findings of the quarantine plugin in each directory and kind.
#
# utils/scripts/check-quarantine-ratchet.py (the test quarantine_ratchet) reads the section
# .crucible.quarantine of each object of the target all, and it counts each distinct finding one
# time.  A count above its row fails the test, because a change can only lower a count (rule R11 of
# misc/01_10_2026_quarantine.md).  A count below its row fails the test too.  Then write the ledger
# again in the same commit, so the ledger keeps no slack:
#     python3 utils/scripts/check-quarantine-ratchet.py --build-dir build --write
#
# THE DIRECTORY
#   The directory of a file is the longest path of a layer row or a quarantine row of
#   utils/scripts/layer-rules.txt that ends with '/' and holds the file, and the first directory under
#   that path.  So test/fixy/test_x.cpp counts in test/fixy, src/canopy/Lifeguard.cpp in src/canopy,
#   include/crucible/Vigil.h in include/crucible, and include/crucible/cntp/Fec.h in
#   include/crucible/cntp.
#
# THE ROWS
#   configuration NAME VALUE   The build that counts: the target machine, and each cache variable
#                              that changes the objects of all or their preprocessor arms.  The check
#                              does not apply to a build of another configuration.
#   DIRECTORY KIND COUNT       The number of findings of the kind KIND in the directory.  The head
#                              comment of utils/tools/quarantine/quarantine.cpp gives the kinds.  A
#                              finding of the kind opted_out is not counted.
