# utils/scripts/libstdcxx-symbols-ledger.txt — the libstdc++ symbols that the libraries of the base and
# libcrucible.a use, for each build kind.  utils/scripts/check-libstdcxx-symbols.py reads it (the test
# libstdcxx_symbols), and the head comment of the check gives the rules.
#
# A kind row:    kind | KIND | TARGET
#   The ledger holds the sets of the build kind KIND (BUILD_DIR/build-kind.txt) on the target TARGET, the
#   value of -march that the compiler gives for the flags of the build.
#
# A symbol row:  KIND | LIBRARY | MARK | CLASS | SYMBOL | DEMANGLED NAME
#   An object of LIBRARY has an undefined reference to SYMBOL, and the libstdc++ of the compiler defines
#   it.  MARK is allow for a symbol of the allowlist of plan section 13.4, and ratchet for each other
#   symbol.  At the S4 gate, no ratchet row can stay.  CLASS is alloc, abi, std, gnu, c or other.
#
# A new symbol fails the test.  A row whose symbol goes fails too, until the same commit writes the rows
# of the kind again:
#   python3 utils/scripts/check-libstdcxx-symbols.py --build-dir build --write
# --write refuses a new ratchet symbol.  The head comment of the check gives the reasons for --raise.
