# utils/scripts/budgets.txt — the thresholds of the compile-time checks that measure a quantity.
# utils/scripts/check_report.py reads this table (read_budgets, classify).
#
# A row:  check | warn | error | unit | what the check measures
#
# A value over the warning threshold gives a warning, which does not fail the check.  A value over
# the error threshold gives an error, which fails it.  A value equal to a threshold does not exceed
# it.  A check that measures time on the shared build host sets its error threshold above the
# noise that the host adds, and states the measured noise in the commit that sets the value.
#
# The targets of the tree: no compile job takes more than 15 s, and no test and no cold fixture
# compile takes more than 10 s.
compile-cpu    | 10 | 20 | s  | the user and system CPU time of one compile job, from the build launcher.  The launcher stops a job at three times the error threshold
compile-memory | 2  | 4  | GB | the peak resident memory of one compile job, from the build launcher.  The launcher fails a job over the error threshold that no ledger row admits
link-time      | 2  | 5  | s  | the user and system CPU time of one link, from the build launcher.  The launcher stops a link at three times the error threshold
link-memory    | 0.5 | 1 | GB | the peak resident memory of one link, from the build launcher.  The launcher fails a link over the error threshold that no ledger row admits
function-size  | 64 | 256 | KB | the size of the largest function in one object.  The Debug build with ASan has the largest functions
object-text    | 512 | 768 | KB | the machine code of one object: the sum of its allocated, executable sections
header-alone   | 8  | 12 | MB | the bytes that one header of include/ includes when it compiles alone, from the ninja dependency log of its sentinel
test-time      | 5  | 20 | s  | the wall time of one test in one ctest run
fixture-cpu    | 5  | 15 | s  | the user CPU time of one negative-fixture compile that the result store does not hold (test/neg_compile_driver.py)
padded-list    | 63 | 63 | elements | the element count of a fixed list whose element type has a padding bit (utils/scripts/check-padded-lists.py). A count above it gives a finding
heavy-include  | 1.25 | 1.25 | x <meta> | the CPU time of one standard header alone (utils/scripts/header-costs.txt) as a multiple of the time of <meta> alone. A header above it is heavy, and a header under include/ does not include it
header-constexpr-ops | 1000000 | 1000000 | operations | the operations of one constant evaluation in a header that compiles alone, the -fconstexpr-ops-limit of its one-line unit in test/layer. GCC gives no warning form of the limit, so the two thresholds are equal
