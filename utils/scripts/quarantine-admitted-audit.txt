# The audit of the standard library names that quarantined code can name.
#
# Each row examines one entry of the admitted list, or one candidate of
# appendix A of misc/01_10_2026_quarantine.md.  The owner reviews each verdict
# before an admitted entry changes.  utils/scripts/check-admitted-audit.py makes
# sure that each admitted entry and each candidate has one row, and that each
# row has a section in test/layer/admitted_flag_matrix.cpp.
#
# One row on each line, with nine fields:
#   NAME | ORIGIN | FLAGS | PREDICTABLE | SAFE | USES | COST | VERDICT | REASON
#
#   NAME         The entry as the admitted list spells it: a qualified name, or
#                a header in angle brackets
#   ORIGIN       admitted: an entry of the admitted list.  candidate: a name of
#                appendix A that the list does not hold.  dropped: an entry
#                that the verdict DROP removed from the list
#   FLAGS        invariant, or varies: the flags that change the name, and how.
#                test/layer/admitted_flag_matrix.cpp holds a static_assert for
#                each property, and the build compiles it under each flag set:
#                Debug, Release, TSan, UBSan-strict, verify, PGO generate, PGO
#                use, -D_GLIBCXX_DEBUG, -D_GLIBCXX_ASSERTIONS, NDEBUG and each
#                contract evaluation semantic.  For the code, the audit compared
#                the text of each definition after the preprocessor under the
#                same flag sets
#   PREDICTABLE  yes, or no and the state that the name reads: a locale, errno,
#                the environment, an allocation, a clock, a path or an
#                exception path
#   SAFE         yes when each use that compiles is safe, or no and the use
#                that is not safe
#   USES         The uses in the tracked C++ files, with the comments and the
#                literals removed: the total and the uses in quarantined files.
#                Then the places that the quarantine plugin reports when the
#                admitted list does not hold the name: the plugin ran with an
#                empty list over each unit of the Debug build, and the count
#                omits the negative fixtures.  Then one place of a use
#   COST         The preprocessed lines that the header of the name adds over
#                the allowance of rule R2 of the plan, and the lines of the
#                header alone.  A line is a non-empty line of `g++ -E -P` in a
#                Debug compile.  The allowance has 34325 lines, and <meta> holds
#                28491 of them alone
#   VERDICT      KEEP, KEEP-RESTRICTED: the restriction that the plugin must
#                enforce, REPLACE: the family that replaces the name, or DROP
#   REASON       Why the verdict holds
#
# A line that starts with '#' is a comment.  Measured on 2026-10-02 at main
# 2864703dc, with the patched GCC 16.2.1 and its libstdc++.
