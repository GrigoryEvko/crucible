# utils/registry.txt — the rules, the jobs and the permitted paths of the utils system.
#
# assay.core.registry reads this file for Python, and cmake/Guards.cmake reads it for CMake.  The rows obey
# the rows grammar of assay.core.rows: a word is a field KEY=VALUE, and " | " divides the cells.
#
#   rule ID engine=ENGINE scope=SCOPE ledger=POLICY [FIELD=VALUE]... doc=REF | WHAT THE RULE REFUSES | THE ACTION
#   job ENTITY module=OWNER[,OWNER...] | WHY THE JOB HAS ONE OWNER
#   path GLOB | WHAT THE FILES ARE
#   term WORD category=CATEGORY | ITS MEANING IN THIS PROJECT
#
# An owner of a job is a module of the package, such as assay.core.proc, or a master, such as bin.guard.  A term row
# gives a word that the STE dictionary refuses, and its category: a technical-noun category noun-N of rule 1.5, or a
# technical-verb category verb-N of rule 1.12.  The rule ste-prose then refuses no shape of the word.
#
# A measured rule has warn, error and unit.  A value over the warning threshold gives a warning, which does not
# fail.  A value over the error threshold gives an error, which fails.  A value equal to a threshold does not
# exceed it.  Change a threshold only with a measurement, and give the numbers in the commit: the rule history
# holds it.  The unit G is 10^9 instructions.
#
# A rule with legacy=MODULE has its module under assay at this time, and legacy-args gives the words of its
# mode.  A rule with held-by has no module of its own: the rule or the command that it names reads its
# thresholds.  Each other rule has a module in assay/guard/engines/ENGINE/.  `guard explain ID` prints a rule,
# and `guard list` prints the rules.
