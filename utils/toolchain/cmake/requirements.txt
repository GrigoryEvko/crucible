# The one version of CMake and ctest that configures, builds and tests this
# tree.  This file is the only place that gives the version.
#
# Each requirement is the manylinux wheel of CMake on PyPI for one machine,
# with the SHA256 of that wheel.  pip installs the requirement of the host:
#   python3 -m pip install --require-hashes -r utils/toolchain/cmake/requirements.txt
# utils/scripts/install-cmake.sh installs the same wheel with no pip.  Each CI
# job that configures or tests runs that script.  The configure step rejects a
# CMake of another version (cmake/CMakePin.cmake).  The test cmake_pin rejects
# a ctest of another version (utils/scripts/cmake_pin.py).
#
# To change the version, write the new version and the SHA256 of each wheel
# from https://pypi.org/project/cmake/ on the two lines.
