# Gate mutants that no test kills, and why each one may stay.
#
# tools/mutation/run.py weakens one gate at a time.  A mutant that every
# witness survives marks a gate with no witness.  Each such gate either gets
# a witness (a negative fixture or a death test), or gets one line here.
#
# A line here is an EQUIVALENT mutant: the gate it weakens is implied by
# another gate that still holds, so no program can tell the mutant from the
# original.  The reason names the gate that still holds.
#
# Columns, separated by " | ":
#   header | kind | entity | the gate text, whitespace squeezed | reason
#
# For a deleted declaration, the gate text is the declaration up to "= delete".
# The key is the gate text, not a line number, so a line shift does not
# make a row stale.
