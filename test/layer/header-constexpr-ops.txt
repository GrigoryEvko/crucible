# The headers that need a constant evaluation of more operations than the
# limit of a header alone, one row each:
#
#   <layer>/<path>.h | limit | reason
#
# test/layer/CMakeLists.txt compiles each header alone with
# -fconstexpr-ops-limit at the error threshold of the row
# header-constexpr-ops in utils/scripts/budgets.txt.  An evaluation of more
# operations runs where the header stands, in each translation unit that
# includes the header, so it stops the build.  A row gives its header the
# limit of the row in place of that threshold.  The limit of a row is more
# than the threshold.  The test header_constexpr_ops compiles each listed
# header alone at the threshold, and it fails when the header compiles, so
# a row goes in the commit that makes its evaluation lazy or small.  The
# list can only become shorter.  A reason has no semicolon.
